Aufbau

Eine feste Bühne,
beliebig viele Folien

  • Jede Folie ist ein <section class="slide">. Alle liegen übereinander, genau eine trägt .active.
  • Die Bühne misst immer 1280 × 720 px und wird als Ganzes per transform: scale() an das Fenster angepasst.
  • Deshalb sind alle Maße in Pixeln verlässlich — und die Miniaturen im Register lassen sich exakt herunterrechnen.
<!-- Struktur -->
<main class="deck">
  <section class="slide active">…</section>
  <section class="slide">…</section>
</main>

/* Bühne skalieren */
const s = Math.min(w / 1280, h / 720);
deck.style.transform = `scale(${s})`;

Ein Wert, der alles trägt

Kernpunkt: eine feste Bühne, alles darin in Pixeln. Deshalb sind die Miniaturen im Register exakt dieselbe Folie.

Bewegung

Richtung ist eine Variable

/* Vorwärts: +76px, rückwärts: −76px */
.deck                 { --enter:  76px }
.deck[data-dir=back]  { --enter: -76px }

.slide         { transform: translateX(var(--enter)) }
.slide.active  { transform: none }
.slide.leaving { transform: translateX(calc(var(--enter) * -1)) }

/* Der Balken oben — eine Zeile */
bar.style.transform = `scaleX(${(i+1) / n})`;

Ein Vorzeichen entscheidet über die Blickrichtung

  • Die neue Folie kommt von der Seite herein, aus der geblättert wird — die alte verlässt die Bühne in dieselbe Richtung.
  • Innerhalb der Folie treten die Elemente gestaffelt auf: animation-delay: calc(var(--i) * 75ms).
  • Der Fortschrittsbalken ist ein scaleX() mit Ursprung links, kein Neuberechnen der Breite.
  • Bei prefers-reduced-motion fällt jede Bewegung weg, der Inhalt bleibt vollständig.
Auf das Vorzeichen hinweisen — eine Variable erzeugt beide Richtungen. Danach eine Einblendung vorführen.

Folienformat, 1280 × 720 für 16:9
  • Der Kopfkommentar ganz oben in der Datei führt dieselbe Liste — man muss nicht suchen.
  • Register, Übersicht, Fortschrittsbalken und Zifferntasten richten sich nach der Zahl der Folien.
  • Alles liegt in einer Datei, auch die Schriften. Kopieren genügt.
Wichtigste Folie für alle, die selbst etwas ändern. Auf den Kopfkommentar in der Datei verweisen.

Vortragen

Zwei Bildschirme, ein Zustand

  • P öffnet dieselbe Datei ein zweites Mal — als Vortragendenansicht mit aktueller Folie, nächster Folie, Notizen und Uhr.
  • Dieses zweite Fenster auf den Laptopbildschirm ziehen, im ersten F für Vollbild auf dem Beamer drücken.
  • Geblättert wird in beiden Fenstern — der Zustand bleibt gekoppelt, auch die Einblendungen.
  • Notizen stehen als <aside class="notes"> in der Folie und sind im Foliensatz unsichtbar.
<section class="slide">
  …
  <aside class="notes">
    Hier stehen die Sprechnotizen.
  </aside>
</section>

Beide Fenster sprechen über postMessage — das trägt auch bei file://
